email-deliverability-check

Find out why a domain's mail lands in spam

Checks the things that actually put mail in the spam folder: the SPF ten-lookup limit, duplicated records, DKIM keys that have been revoked, DMARC stuck at p=none, and a missing MTA-STS policy. DNS only - no access to the mailbox is needed, which makes it usable on a prospect's domain.

Source on GitHub Work with me

What it does

  • Resolves and counts SPF lookups the way a receiving server does.
  • Batch mode for a list of client domains, with CSV output.

How it is proved

17 offline checks over recorded DNS answers.
