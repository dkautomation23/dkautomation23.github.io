webhook-rewind

Record webhooks once, replay them re-signed

A webhook handler breaks in production and you need the payload that broke it. The provider will send you the next event, not that one. A payload copied out of a log fails signature verification, because every provider signs the raw bytes. webhook-rewind keeps the body as bytes from capture to replay and re-signs it with your own secret.

Source on GitHub Work with me

What it does

  • Captures every inbound request to a JSON Lines file, answering 200 immediately so the provider does not back off.
  • Re-signs on replay for Meta (WhatsApp, Instagram, Messenger), GitHub, Shopify and Stripe.
  • Gives Stripe a fresh timestamp, because its tolerance window rejects the recorded one.
  • Redacts Authorization, Cookie and API-key headers before anything reaches disk.

How it is proved

Every signing scheme is checked against an independent implementation of the verifying side, not against a frozen digest. 34 tests, none of which touch a network.
