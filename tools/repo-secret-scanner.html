repo-secret-scanner

Catch the key before the push, in one file

A key in a commit is public the moment it is pushed and stays in the history after it is deleted, so the only cheap moment to catch it is before the push. The scanners that do this well want an install, a config file and a service account; this is one Python file with no dependencies that exits non-zero on a hit, which is all a pre-commit hook or a CI step needs.

Source on GitHub Work with me

What it does

  • Nine rules for the shapes that actually leak: AWS access keys, GitHub, Slack and Google tokens, Stripe live keys, OpenAI-style keys, PEM private-key blocks, JWTs, and bare api_key or password assignments.
  • Findings are always redacted to first and last four characters plus a length - a report that prints the secret in a CI log has moved the leak rather than stopped it.
  • --selftest plants a dummy secret and confirms it is caught, so a broken scanner cannot sit there quietly reporting clean.
  • --entropy is opt-in, because flagging every long string is how a gate gets switched off.

How it is proved

One file, 167 lines, no dependencies; selftest passes on a planted secret. It is the gate I run over my own repositories before every push.
