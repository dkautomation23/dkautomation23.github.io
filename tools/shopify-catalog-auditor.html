shopify-catalog-auditor

The catalogue gaps that quietly cost sales, without store access

Merchants export their whole catalogue to spreadsheets just to find what is broken: products with no image, descriptions of nine words, sold-out pages still collecting clicks. This reads any Shopify store from the outside — no API key, no app install, no permission needed — and returns a prioritised report and a CSV fix-list in under a minute.

Source on GitHub Work with me

What it does

  • Reads the public storefront the way a shopper's browser does, so there is nothing to install and nobody to ask.
  • Ranks what it finds by what it costs, not by how many there are: one sold-out bestseller outranks forty tidy typos.
  • Writes a CSV keyed by product, so the fix list goes straight to whoever edits the catalogue.

How it is proved

20 of 20 self-checks pass offline. Runs against any live store from a domain alone.
