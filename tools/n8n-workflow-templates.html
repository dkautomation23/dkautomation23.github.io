n8n-workflow-templates

Seven imports for the jobs that come up every time

Capturing leads, digesting feeds, pushing form submissions into a CRM without creating duplicates, and receiving an authenticated webhook that answers with a proper status code. Each file is a clean export: import it, plug in credentials, run. The value is in the parts people get wrong the first time — de-duplication, authentication, and the response code a sender actually reads.

Source on GitHub Work with me

What it does

  • De-duplication is built in, because the second submission of the same form is the normal case and a duplicate CRM record costs someone an hour.
  • The webhook template answers with a real status code, which is what decides whether the sender retries.
  • A validator in CI parses every export, so a template that would fail on import fails here first.

How it is proved

7 of 7 templates validate in CI, parsed as n8n exports rather than eyeballed as JSON.
