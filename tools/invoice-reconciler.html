invoice-reconciler

Match a bank statement against open invoices

Matches payments to invoices in five passes - references, part payments, batch transfers, instalments - and reports only what does not add up. The cases that make manual reconciliation slow are the ones it is built around.

Source on GitHub Work with me

What it does

  • Detects the date convention of each file rather than assuming one.
  • Drops a shortfall that a later payment covered, instead of reporting it twice.
  • Writes the exception list as CSV or JSON for whoever has to chase it.

How it is proved

Standard library only: it runs on any Python 3.10+ with nothing installed.
