csvdiff

Diff two CSV exports by key and see what actually changed

"The data does not match after the migration" is a week of work, and it always starts with two exports and a spreadsheet. csvdiff compares them by key and reports what moved, per column, with the transitions counted.

Source on GitHub Work with me

What it does

  • Two million rows, 131 MB, in 2.8 seconds, holding about 60 bytes per row of the old file.
  • Treats 1000, 1000.00 and 1.000,00 as one value, and empty, NULL, NaN and \N as one nothing - while keeping the cents in money.
  • Calls out broken rows and duplicate keys instead of quietly diffing them.
  • Exit code 1 when anything differs, so it works as a gate.

How it is proved

The benchmark is a script in the repository: it builds both exports from a fixed seed, so the timing repeats on any machine.
