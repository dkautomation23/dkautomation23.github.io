instagram-metrics-reader

Creator metrics that are never older than they claim

A creator marketplace shows a follower count on a profile card, and that number has to be true. The awkward parts are not the API call: dozens of connected creators share one rate limit, tokens expire every sixty days, and a card showing a stale number while implying it is live is worse than showing nothing.

Source on GitHub Work with me

What it does

  • Read-only scopes are enforced in the code, not merely requested — the app cannot post even if something later asks it to.
  • Every stored number carries when it was fetched, and the card shows that age rather than implying freshness.
  • Token expiry and the shared rate limit are handled as normal states with a plan, not as errors that surface to the creator.

How it is proved

31 tests pass on a clean machine. The whole flow runs with python run_demo.py — no Meta app, no Facebook Page, no tokens.
