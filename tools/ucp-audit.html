ucp-audit

Is your shop reachable by AI shopping agents?

Google and Shopify's Universal Commerce Protocol lets AI agents shop: every business publishes a machine-readable profile at /.well-known/ucp and agents read it to decide what they can do with that shop. The failure mode is silence - offer checkout without declaring a searchable catalogue and no agent will ever surface your products, with no error page and no warning anywhere.

Source on GitHub Work with me

What it does

  • Reads the profile the way an agent does and reports what an agent would conclude.
  • Catches the case that matters most: checkout offered while catalog.search and catalog.lookup are missing, so an agent can pay for what it already knows about and discover nothing.
  • Finds the contradictions a profile carries silently - a capability requiring a newer protocol than the profile declares, an extends pointing at a capability that is not offered, a plaintext endpoint, a transport with nowhere to send a request.
  • Compares your protocol version against the published spec, because each release has added shopping capabilities.

How it is proved

Run against chewy.com on the day it was written: checkout, fulfilment and order declared, neither catalogue capability, protocol seven months behind. allbirds.com the same day: eight capabilities on the current version. Both profiles are recorded in the repository as test fixtures.
