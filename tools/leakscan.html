leakscan

See what leaves with a file before you send it

An offline check of everything a file carries that you did not mean to send: tracked changes with the deleted text still readable, review comments, worksheets hidden at the veryHidden level, attachments inside a PDF, GPS coordinates in photos, and validated card and IBAN numbers.

Source on GitHub Work with me

What it does

  • Reads the file formats directly - no network access at any point, so it is safe on material that must not leave the machine.
  • Validates card and IBAN numbers rather than matching digit patterns, which is the difference between a finding and noise.
  • Reports what it found and where, and changes nothing.
