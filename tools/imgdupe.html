imgdupe

The same photo twice, found by what it looks like

Byte-comparison finds only files that are literally identical, and misses the case everyone actually has: the same photo at 4K and at 1920, the JPEG re-saved by a phone, the export that changed nothing but the metadata. This groups by what a picture looks like, tells you which copy to keep, and never deletes anything.

Source on GitHub Work with me

What it does

  • Perceptual hashing, so a resize or a recompress lands in the same group as its original.
  • Complete-linkage grouping, so unrelated pictures never chain together through a shared near-neighbour — the failure that makes a duplicate finder untrustworthy.
  • It writes a delete script instead of deleting: the decision stays with the person who knows which copy matters.

How it is proved

31,662 JPEGs from a real photo folder hashed in 37 seconds on 16 threads. 23 tests, plus a benchmark that rebuilds its own test folder so the grouping can be checked rather than believed.
